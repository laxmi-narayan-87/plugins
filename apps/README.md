**Source:** ChatGPT app directory — https://chatgpt.com/plugins  
**Discovery:** ChatGPT Plugin Management catalogue search in ChatGPT. Descriptions below are concise summaries of catalogue listings.

## Important distinction

This catalog does **not** contain the source code or complete downloadable packages for these apps. They are third-party ChatGPT integrations. To archive a full package under `plugins/<name>/`, the source must be publicly available or supplied as an export and its license must permit copying/redistribution.

## Maintenance

- Recheck app availability and listing details before installation.
- Keep app catalog entries separate from Plugin Creator-owned packages.
- Record the date and source for each refresh.
- Do not store secrets, credentials, or private connection data in this repository.
