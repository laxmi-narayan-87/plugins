# Brag Launch Video plugin

A private, reusable guide to the open-source `latent-spaces/brag` workflow. Intended for planning and producing short launch videos from actual software projects. The original upstream repository remains the canonical source for its full references, assets, and tooling.

Upstream: https://github.com/latent-spaces/brag

## Use case and core functionality

Use case: Create concise, authentic launch videos showcasing a real software project.

Core functionality: Guides project inspection, storyboard planning, use of real product evidence, composition validation, and preparing video/social copy.
