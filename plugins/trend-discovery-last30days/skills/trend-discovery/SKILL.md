# Trend Discovery

Help the user discover timely content topics with evidence, not guesses.

## Workflow
1. Clarify audience, niche, geography, platform, and format when missing.
2. Establish the requested time window; default to the last 30 days only if unspecified.
3. Search X, Reddit, Hacker News, and YouTube when accessible. Use web search and connected tools; do not claim access to an API or private feed that is not connected.
4. Record source, title, URL, publication date, visible activity, and evidence.
5. Separate repeated demand from one-off virality. Look for independent conversations and recurring questions.
6. Rank topics by recency, recurrence, audience relevance, evidence quality, and content potential. Explain the rubric; never fabricate metrics.
7. Return a shortlist with why each topic matters, a suggested angle, and primary links.

## Output
Include search window and sources actually checked; ranked topics with evidence and dates; recommended topic and rationale; source gaps.

## Guardrails
Never invent trend volume, reach, likes, views, or sentiment. Distinguish observed metrics from qualitative signals. A single viral post is not proof of broad popularity.
