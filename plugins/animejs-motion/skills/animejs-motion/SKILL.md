name: animejs-motion
description: Design polished web animations with Anime.js.
---

Use when designing interactive web animations, timelines, SVG motion, staggered effects, or micro-interactions using Anime.js.

Workflow:
1. Ask for or infer the DOM/SVG target, interaction trigger, duration, easing, stagger, reduced-motion behavior, and framework.
2. Translate the motion brief into a timeline: targets, properties, keyframes, delays, overlaps, and lifecycle.
3. Offer accessible, performant implementation guidance that avoids layout thrashing and cleans up animations when components unmount.
4. Check the user's Anime.js version and current official API docs before writing version-specific syntax.
5. Include reduced-motion alternatives, keyboard and touch considerations, and a quick verification checklist.

Do not claim animations were run in the user's browser. Do not introduce dependencies or alter unrelated UI behavior without permission.
