name: remotion-skills
description: Apply reusable Remotion production and code-review workflows.
---

Use when a task needs structured Remotion project planning, implementation review, code quality checks, or production handoff.

Workflow:
1. Determine whether the user needs project scaffolding, a new composition, an existing-project change, render troubleshooting, or code review.
2. Provide a checklist-driven workflow for composition design, props and data validation, font and asset loading, timing, audio, transitions, and render settings.
3. Review code for deterministic frame-based behavior, reusable components, responsive composition design, asset correctness, and maintainability.
4. Verify version-specific Remotion APIs from official docs or supplied project sources before giving exact code.
5. Provide a focused implementation plan, test checklist, and reproducible render command.

This plugin supplies workflow guidance, not the upstream Remotion CLI or runtime. Do not imply it can inspect a local repository or render media unless an appropriate tool or files are actually connected.
