# Serena Coding Agent Guide

A private ChatGPT plugin package with a focused skill for setting up and using the Serena coding agent and its MCP server.

Serena source: https://github.com/oraios/serena

This package contains instructions only. It does not bundle or host Serena, nor does it declare a remote MCP endpoint because Serena is generally launched locally or on an explicitly configured HTTP endpoint.

## Use case and core functionality

Use case: Configure and use Serena semantic coding agent for codebase-aware development.

Core functionality: Setup and MCP guidance, semantic code navigation, repository understanding, and coding workflow support.
