# Pin UI Components

Official source: https://www.pinui.xyz/components

Pin UI describes its components as single-file components inspired by Pinterest pins; each has a live preview and copyable source. Its catalog showed 27 components across inputs & controls, cards & widgets, audio & media, and lists & pickers. Examples include Search Card, Selection List, Desk Computer, Liquid Voice, File Box, Copy Paste Pad, Progress Image, Prompt Composer, Dynamic Drop Zone, Lamp Switch, Joystick, Chips, OTP Input, Task Card, Magnify, Calendar, Swap Card, Thermal Dial, Weather, Taxi, Balance Card, Cart Card, Recorder, Chat Room, Liquid Tabs, Add Member and Countdown.

## Workflow
1. Open the exact component page and inspect the live behavior and source.
2. Confirm whether the component is truly self-contained or depends on packages, assets, CSS variables or browser APIs.
3. Copy only the needed component and assets; do not scrape/rehost the entire catalog.
4. Integrate into the project's conventions and test keyboard, touch, focus, responsive and reduced-motion behavior.
5. For media components, verify permission prompts, recording behavior, browser support and graceful fallback.

The site says users own the single-file component after copying; still inspect the current license/terms and retain any required attribution. This is an independent reference workflow, not an official Pin UI integration.
