# Superpowers Workflow (ChatGPT plugin adaptation)

A skills-only adaptation inspired by [`obra/superpowers`](https://github.com/obra/superpowers).

Includes a portable `superpowers-workflow` skill covering task understanding, planning, TDD, systematic debugging, code review, safe Git practices, and verification-before-completion.

## Compatibility note

This is not a complete clone of the upstream repository. Upstream supports different coding-agent harnesses and may use session hooks, scripts, and a separately maintained skill library. This plugin package provides workflow instructions only and does not claim those external runtime features are installed or active.
