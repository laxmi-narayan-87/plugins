# DESIGN.md Guide Plugin

A skills-focused private plugin adapted from public project guidance in [`google-labs-code/design.md`](https://github.com/google-labs-code/design.md).

## Included workflows

- `design-system-authoring`: Draft or improve DESIGN.md design-system documents with structured tokens and specific narrative intent.
- `design-review`: Review structure, token references, accessibility risks, and changes between revisions.

## Important note

The upstream DESIGN.md format is described as alpha. This plugin provides workflow guidance; it does not itself execute the upstream CLI. Run the suggested lint, diff, or export commands in an environment with Node.js/npm to verify concrete output.

The upstream repository's LICENSE should be reviewed for the exact terms governing reuse. This plugin contains workflow guidance based on the project documentation rather than a bundled copy of the full repository.
