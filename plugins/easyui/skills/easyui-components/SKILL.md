# EasyUI Components

Official source: https://easyui.site

EasyUI describes itself as a collection of beautiful React components for modern interfaces. Observed components include Interactive Area Chart, LockInput, OriginDropdown, SlidePagination, UnfoldAccordion, Liquid Toggle, Gooey Menu, Pill Navigation and Neon Edge Button.

## Best-fit use cases
- Forms and controls: LockInput and Liquid Toggle.
- Navigation: OriginDropdown, Gooey Menu and Pill Navigation.
- Content navigation: SlidePagination and UnfoldAccordion.
- Data presentation: Interactive Area Chart.
- Visual emphasis: Neon Edge Button.

## Workflow
Open the exact component page before implementation and copy the current official install/source instructions. The homepage scrape did not expose a reliable universal package/CLI contract, so do not invent one. Check framework and styling compatibility, dependencies, responsive behavior, focus and hover states, keyboard operation, contrast, reduced motion and chart semantics. For charts, ensure axes, units, labels and accessible summaries communicate the data accurately.

This is an independent reference skill, not an official EasyUI plugin. Preserve upstream license and attribution requirements.
