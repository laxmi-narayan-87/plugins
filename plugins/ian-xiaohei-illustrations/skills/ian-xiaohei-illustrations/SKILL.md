# Ian Xiaohei Illustrations — Article Illustration Skill

## Goal
Turn one key judgment, process, structure, state, or metaphor from a piece of writing into a memorable explanatory illustration. This is not a default request for a slide, infographic, commercial key visual, cute cartoon, or dense poster.

The visual direction is a clean white background, loose black hand-drawn lines, generous negative space, and only a few red, orange, or blue handwritten annotations. A recurring character called Xiaohei is a solid black, minimal figure with white-dot eyes and thin legs. Xiaohei must participate in the central action, not merely decorate a corner.

## Workflow

### 1. Understand the source
Read the supplied prose, article, Markdown, screenshot, or accessible link. Identify:
- the main claim and any meaningful turn in reasoning;
- passages where a visual would reduce cognitive load;
- passages that are better left as text;
- the audience and the intended role of each image.

Do not assign an image to every paragraph. Select cognitive anchors such as a crucial judgment, a handoff, a split, a before/after state, a feedback loop, a role transition, or a useful metaphor.

If a link cannot be accessed, ask the user to paste the relevant excerpt instead of inventing the article's content.

### 2. Plan before rendering
Unless the user explicitly asks for an immediate single image, provide a concise shot list first. For each image specify:
- placement (which paragraph or idea it follows);
- title or short theme;
- one-sentence central meaning;
- structure type (metaphor, comparison, workflow, system detail, state change, layered method, map/route, or mini-comic);
- what Xiaohei is doing;
- the key objects and short Chinese annotations.

Default to 4–8 images for a substantial article, 1–3 for a short piece, and rarely more than 9. Avoid duplicate visual metaphors and unnecessary images.

### 3. Invent an original metaphor
Create a new low-tech, slightly absurd but understandable physical metaphor from the current text. Example forms include a leaking bucket, an overloaded lever, a hand-built bridge, a peculiar sorting device, or an impossible but coherent machine—but do not reuse an example just because it exists. Never copy an example's exact composition, objects, or labels unless the user explicitly asks to reproduce that example.

Each image should communicate one core action or relationship only.

### 4. Image-generation brief
When an image-generation tool is available and the user asks to create an image, generate each illustration as a separate image rather than a contact sheet. Give every image a 16:9 landscape composition and specify:
- pure white background; no paper texture, beige cast, gradients, or shadows;
- thin, slightly imperfect black hand-drawn linework;
- generous whitespace; main drawing occupies roughly 40–60% of the frame;
- just a few red/orange/blue handwritten Chinese annotations;
- Xiaohei performs the central action;
- no dense paragraphs, generic clip-art, slide-deck boxes, corporate infographic styling, or decorative title in the upper-left corner.

If image generation is unavailable, provide production-ready prompts and do not claim that files were generated.

### 5. Editing requests
When the user asks to edit a supplied image, preserve every element not explicitly targeted. State which changes are requested, then use the available image-editing capability. Do not claim an edit was applied unless an edited asset was actually produced. If the request is ambiguous, make the smallest reasonable change and preserve the composition.

### 6. Quality review
Review every generated result against the checklist below. If a failure is material, iterate when image generation/editing is available; otherwise describe the required correction clearly.

## QA checklist
- Background is clean white.
- Linework is hand-drawn, black, and not overly polished.
- Whitespace is generous.
- The image communicates one idea rather than many.
- Xiaohei performs the core action and is not a decorative mascot.
- Color annotations are restrained and brief.
- Chinese text is short, legible, and free of obvious misspellings.
- The image does not look like a PowerPoint slide or conventional infographic.
- No unintended heading, watermark, extra character, or unrelated object appears.
- The metaphor is newly invented for the current source rather than copied from a sample.

## Delivery
When actual images were produced, report the number generated, each image's purpose, the exact saved path or attachment, and any limitations found during review. Do not invent paths. If only prompts or a shot list were produced, label them accordingly.
