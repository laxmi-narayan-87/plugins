# Quality Checklist

Check each item after generation:
- [ ] 16:9 landscape
- [ ] Pure white background
- [ ] Thin, slightly imperfect black hand-drawn linework
- [ ] Ample whitespace
- [ ] One central idea
- [ ] Xiaohei performs the central action
- [ ] Accent colors are sparse and intentional
- [ ] Chinese labels are short and legible
- [ ] No unwanted title, watermark, stray text, or unrelated objects
- [ ] Not a conventional PPT or dense infographic
- [ ] Metaphor and composition are fresh for the source

If there are minor text errors, shorten the labels before regenerating. If the whole image is too dense, remove objects rather than shrink everything. If Xiaohei is decorative, redesign the action rather than simply moving the character.
