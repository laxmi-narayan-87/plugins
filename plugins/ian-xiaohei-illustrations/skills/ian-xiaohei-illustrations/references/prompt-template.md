# Prompt Template

Create one 16:9 landscape explanatory illustration for a Chinese article.

Core idea: [ONE sentence]
Audience/context: [brief context]
Physical metaphor: [new metaphor derived from this idea]
Xiaohei's central action: [specific action that changes or reveals the metaphor]
Essential objects: [short list]
Optional Chinese annotations: [up to a few short labels]

Visual style: pure white background, loose thin black hand-drawn lines, generous whitespace, only a few red/orange/blue handwritten annotations, clean but slightly absurd and inventive. Main drawing occupies roughly 40–60% of frame.

Composition must make the central relationship instantly readable. Xiaohei is part of the action, not decoration.

Avoid: slide deck / PPT look, generic infographic cards, corporate clip-art, childlike cuteness, gradients, shadows, beige or paper texture, large title banners, long paragraphs, unnecessary labels, old sample composition, watermarks, unrelated objects.
