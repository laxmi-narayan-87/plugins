# Ian Xiaohei Illustrations — Private Plugin Package

This package adapts the public `helloianneo/ian-xiaohei-illustrations` Codex skill into a plugin-ready skill bundle.

It helps plan, prompt, and quality-check sparse 16:9 hand-drawn illustrations for Chinese articles. It does not contain the source project's example images or imply endorsement by the original author.

## Included
- Main skill instructions
- Style DNA reference
- Xiaohei character guide
- Composition and metaphor guidance
- Prompt template
- QA checklist

Use the skill to prepare a shot list, draft image prompts, or review illustration outputs. Actual image generation/editing depends on whether the current ChatGPT session provides those capabilities.

## Use case and core functionality

Use case: Create and review sparse, hand-drawn 16:9 illustrations for Chinese articles and essays.

Core functionality: Cognitive-anchor discovery, visual metaphor and composition guidance, prompt drafting, shot planning, and illustration QA.
