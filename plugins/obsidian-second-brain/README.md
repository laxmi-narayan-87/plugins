# Obsidian Second Brain

A private skills-first plugin that turns the Claude Code + Obsidian idea into a practical, safe setup and operating playbook.

Install one agent integration first (default: Claudian), optionally add Smart Connections, and use Local REST API only when an external MCP client needs vault access. Copilot and Agent Client are alternatives. Smart Composer and YOLO should not be used together.

See `skills/obsidian-second-brain/SKILL.md` for installation, vault layout, permissions, privacy, and repeatable workflows.
