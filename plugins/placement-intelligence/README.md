# Placement Intelligence

## Plugin name

`placement-intelligence`

## Use case

Research and organize campus placement opportunities, role requirements, eligibility criteria, deadlines, and preparation priorities.

## Core functionality

Provides structured workflows for comparing job descriptions, extracting requirements, tracking application details, and translating role expectations into focused preparation tasks. Verify company information, deadlines, and eligibility on official sources before acting.
