# Aceternity UI

Official sources: https://ui.aceternity.com/components ; https://ui.aceternity.com/blocks ; https://ui.aceternity.com/templates

Aceternity UI describes a React component library built with Tailwind CSS and Motion. Its catalog includes 100+ components, 180+ blocks and Next.js templates. Free component examples include 3D Card Effect, Apple Cards Carousel, Background Beams, 3D Marquee, Wobble Card, Hero Highlight, Liquid Glass, Background Cubes Grid, Cloud Shader, Text Flipping Board, Chromatic Image, Notch, Parallax Hero Images, Squiggly Text, Gooey Input, Magnetic Button, Terminal, ASCII Art, Canvas Text and 3D Globe.

Blocks include hero sections, feature grids, pricing, testimonials, logo clouds, shaders, backgrounds and bento grids. Templates cover full Next.js websites. The homepage marks some blocks as All-Access; verify the current pricing/access gate before promising installation.

## Workflow
1. Choose component vs block vs template based on scope.
2. Confirm current docs, dependencies, install command, license and whether the item is free or paid.
3. Integrate using the project's React/Next.js and Tailwind versions; verify Motion setup and client-component boundaries in Next.js.
4. Optimize animation and 3D effects for mobile, reduced-motion users and low-power devices. Add static fallbacks where practical.
5. Test hydration, performance, keyboard access, focus visibility, contrast and responsive behavior.
