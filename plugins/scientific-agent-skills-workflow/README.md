# Scientific Agent Skills Workflow Plugin

A compact, skills-only plugin inspired by the public [K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills) project.

## Included

- `plugin.json`: Agent Plugins 1.0 manifest.
- `skills/scientific-research-workflow/SKILL.md`: repeatable workflow for research framing, literature synthesis, analysis design, reproducibility, evidence-aware reporting, and domain safeguards.

## Scope

This is not a mirror of the upstream project's full skills catalog, and it does not add live database APIs or scientific execution tools. Use the linked upstream repository and its catalog for specific domain skills and integration instructions.
