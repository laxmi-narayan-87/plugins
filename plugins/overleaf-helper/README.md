# Overleaf Helper plugin

A private ChatGPT plugin package with a repository-grounded skill for understanding the Overleaf source, diagnosing local Community Edition deployments, working through LaTeX problems, and preparing careful open-source contributions.

Source repository: https://github.com/overleaf/overleaf

The package deliberately does not declare an MCP endpoint: no verified Overleaf MCP endpoint or authenticated live-account API was supplied. It provides guidance only and must not claim direct access to Overleaf user projects or the user's machine.

## Use case and core functionality

Use case: Understand Overleaf source, troubleshoot Community Edition and LaTeX issues, and prepare contributions.

Core functionality: Repository-grounded setup guidance, diagnosis, LaTeX help, and contribution workflow; no assumed live account access.
