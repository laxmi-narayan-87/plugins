# Diagram Design — ChatGPT plugin skill package

This is a focused Agent Plugins package adapted from [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design), which is distributed under the MIT License.

The package contains a diagram-design skill with type selection, editorial layout principles, accessibility checks, brand onboarding guidance, import/redraw workflow, and quality gates. It does **not** port the upstream repository's complete example gallery, Python import/export scripts, slash commands, or client-specific marketplace integrations into executable ChatGPT tools.
