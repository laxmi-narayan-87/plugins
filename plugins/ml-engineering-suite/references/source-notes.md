# Provenance and source notes

This plugin combines five user-owned ML workflow plugins into one package while preserving their distinct skill workflows: model development, data quality and labeling, hyperparameter tuning, MLOps pipelines, and deployment. The workflow text is an original synthesis maintained in those plugins, not a verbatim copy of third-party upstream SKILL.md files.

The original plugin source notes referenced these community resources (checked 2026-10-25):
