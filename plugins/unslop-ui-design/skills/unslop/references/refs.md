# Reference qualities

Original examples are described in the source repository: https://github.com/heydamir/unslop/tree/main/skills/unslop/references

Learn from these principles, never copy their subject, palette, or layout:
- One meaningful rich visual moment; quiet chrome around it.
- Product-specific materials and content, rather than generic decoration.
- Headlines placed on calm space and supported by a real product view.
- Charts where color encodes data, not decoration.
- A coherent visual language carried across the whole screen.
