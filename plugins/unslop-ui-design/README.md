# Unslop UI Design

A ChatGPT skills-only adaptation of [heydamir/unslop](https://github.com/heydamir/unslop), the interface-refinement skill created by Damir Sokolovsky (@heydamir).

## Use case

Review a dashboard, app, or landing page that looks generic or AI-generated. Audit it for visual clichés, derive a distinct direction from the actual product, and refine the interface without changing its core functionality, content, or information architecture.

## Core functionality

- Audit UI for visual, typography, spacing, copy, component, landing-page, and motion problems.
- Decide whether the screen needs a full redesign, light polish, or no changes.
- Propose a five-part product-specific direction before editing.
- Guide improvements in nine ordered passes: spacing, color, icons, copy, type, layout, details, visuals, and motion.
- Verify the result against the audit and report changes.
- Preserve the source creator's attribution and license.
