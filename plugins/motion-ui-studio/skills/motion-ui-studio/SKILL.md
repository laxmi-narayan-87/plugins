name: motion-ui-studio
description: Build accessible UI transitions with Motion.
---

Use when creating motion-rich interfaces, page transitions, gestures, layout animations, or interactive React components with Motion.

Workflow:
1. Identify framework, Motion package/version, component states, gesture requirements, and desired motion character.
2. Design motion as state transitions with clear initial, animate, exit, and layout behavior where supported.
3. Produce small composable patterns and explain component lifecycle and presence handling.
4. Respect reduced-motion preferences, focus behavior, keyboard access, and touch interactions.
5. Check current official Motion docs and installed version for import paths and API names before presenting code.

Treat animation as progressive enhancement: core content and controls must remain usable without motion. Do not claim runtime verification without an actual browser/test tool.
