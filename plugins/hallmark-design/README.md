# Hallmark Design plugin

A skills-first ChatGPT plugin adaptation of the Hallmark design workflow.

- **Name:** Hallmark Design
- **Use case:** Create, redesign, polish, or audit interfaces without generic template-like UI, while maintaining accessibility, responsive behavior, and working functionality.
- **Core functionality:** Pre-flight repository inspection; product-specific visual direction; first-screen-first implementation; purpose-led layout; redesign preservation inventory; UI audit severity tiers; responsive/accessibility quality gates; accurate implementation handoff.
- **Original source:** [Nutlope / Hallmark](https://github.com/Nutlope/hallmark) — made by Nutlope / Together AI. Website: [usehallmark.com](https://www.usehallmark.com).
- **License:** Upstream repository declares MIT. This package adapts workflow guidance and does not include the upstream theme catalog, photos metadata, or executable scripts.

Invoke the skill for a new build, `/hallmark redesign <path>`-style redesign task, or audit-only review of an existing interface.
