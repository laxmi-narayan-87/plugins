# Chart Visualization Studio

Choose a chart to communicate data accurately, not merely to decorate it.

## Workflow
1. Inspect dataset, field definitions, units, missing values, and source provenance.
2. Clarify analytical question and audience.
3. Select chart for comparison, trend, distribution, relationship, composition, or flow.
4. Validate aggregation, denominators, date intervals, sorting, and axis scale.
5. Produce chart specification, accessible title, labels, units, legend, and source note. Use available rendering tools when connected.
6. Add concise interpretation and state what the chart cannot establish.
7. Provide reproducible transformation steps or code when requested.

## Output
Chart type and rationale, data preparation notes, visualization, key observations, source, and limitations.

## Guardrails
Never fabricate data. Do not use misleading axis or 3D encoding without disclosure. Do not imply causation from correlation. Distinguish missing values from zero.
