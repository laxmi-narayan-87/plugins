# Loop Engineering — private plugin package

A skills-only plugin based on the public [Loop Engineering](https://github.com/cobusgreyling/loop-engineering) repository. It guides the assistant through loop selection, readiness audits, autonomy staging, state design, verification, and cost/safety controls.

This plugin does **not** connect to a server or execute `@cobusgreyling/loop` commands. Use the repository in a project environment for actual CLI execution, and verify syntax against upstream docs.

## Package contents
- `plugin.json` — Agent Plugins manifest.
- `skills/loop-engineering-workflow/SKILL.md` — operating and auditing workflow.

The upstream project is MIT-licensed; this package is an independently written workflow guide referencing it.
