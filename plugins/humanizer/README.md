# Humanizer

## Use case
Edit AI-sounding prose into natural, clear writing while preserving original meaning and facts.

## Core functionality
- Provides a focused workflow and instructions for the plugin's domain.
- Helps structure tasks, ground recommendations in available evidence, and identify prerequisites or limitations.
- Does not claim external actions or runtime execution unless a connected tool actually performs them.
