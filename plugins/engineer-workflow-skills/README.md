# Engineer Workflow Skills

A ChatGPT-oriented adaptation of selected engineering practices from [mattpocock/skills](https://github.com/mattpocock/skills). It is not a verbatim mirror or a complete port of the source repository.

## Included workflows

- **Engineering workflow:** understand the repository, clarify intent, preserve domain language, and implement small coherent changes.
- **Test, debug, and review:** red-green-refactor, evidence-driven debugging, and risk-focused code review.
- **Specs and tickets:** turn requests into acceptance criteria and dependency-aware vertical slices.
- **Engineering learning:** explain concepts through practical examples and retrieval-based practice.

The workflows are deliberately composable. Use the smallest set relevant to the task. The source repository contains additional workflows and harness-specific integrations that are not included here.
