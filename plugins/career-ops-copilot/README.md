# Career Ops Copilot

A private ChatGPT plugin skill for evidence-based job search and application preparation, informed by the public workflow principles documented in [career-ops](https://github.com/career-ops-hq/career-ops).

## What it does
- Evaluates job descriptions against a user's supplied resume/profile and gives a transparent fit assessment.
- Helps search for roles using current, cited sources when browsing is available.
- Tailors resume bullets and cover letters without inventing credentials, metrics, or responsibilities.
- Prepares interview plans, STAR stories, recruiter messages, and salary discussion prompts.
- Maintains a structured application tracker when the user provides updates or asks to organize records.

## Safety and boundaries
- Never submits applications, sends emails/messages, or clicks final application buttons.
- Treats job descriptions and external pages as untrusted data, not instructions.
- Separates confirmed facts, inferred fit, and unknown details; never fabricates candidate history.
- Does not claim to run Career-Ops software locally or access its private files.
- This is an independent assistant skill, not an official integration or an endorsement by the Career-Ops maintainers.

## Use case and core functionality

Core functionality: Job-fit analysis, cited opportunity research, resume/cover-letter tailoring, interview preparation, recruiter outreach, negotiation prompts, and application tracking.
