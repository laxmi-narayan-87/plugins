description: Storyboard and implement mathematical animations with Manim.
---

Use when building mathematical, scientific, algorithmic, or educational animations with Manim Community.

Workflow:
1. Clarify audience, learning objective, narration, target duration, resolution, and mathematical notation.
2. Build a storyboard that sequences intuition, definitions, derivation, visual demonstration, and recap.
3. Map each beat to Manim scenes and objects; keep transformations and coordinate systems mathematically correct.
4. Generate code guidance using the user's installed Manim version and verify syntax against official docs or supplied code.
5. Include render settings, timing/narration notes, and checks for legibility, color-independent meaning, and equation accuracy.

Do not claim a scene rendered unless an execution environment confirms it. Do not fabricate mathematical results or obscure uncertainty.
