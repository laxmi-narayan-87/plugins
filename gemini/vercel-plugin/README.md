# Vercel Plugin

**Name:** Vercel  
**Use case:** Build, optimize, and deploy modern web applications and AI agents on Vercel with comprehensive platform skills and the Vercel MCP server.  
**Core functionality:**
- Next.js and Vercel AI SDK guidance (chat, tool calling, multi-agent systems, durable workflows).
- Deployment management, CI/CD, preview URLs, domain configuration, and environment variables.
- React best practices and performance optimization (bundle size, server components, re-renders, caching).
- Vercel Firewall, BotID, Flags SDK, Custom Metrics, and OpenTelemetry Tracing.
**Original source:** [vercel/vercel-plugin](https://github.com/vercel/vercel-plugin)
