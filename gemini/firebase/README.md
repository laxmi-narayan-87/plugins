# Firebase Plugin

**Name:** Firebase  
**Use case:** Prototype, build, and run modern web and mobile applications using Firebase's backend, AI, and operational infrastructure.  
**Core functionality:**
- Cloud Firestore databases, security rules authoring, auditing, and indexing.
- Firebase Authentication, App Hosting, and static Hosting management.
- Firebase Data Connect with PostgreSQL backends.
- Firebase AI Logic integration (Gemini API) and Crashlytics diagnostics.
- Xcode iOS project setup and Firebase Remote Config management.
**Original source:** [firebase/agent-skills](https://github.com/firebase/agent-skills) (Official Site: [firebase.google.com](https://firebase.google.com))
