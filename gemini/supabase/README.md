# Supabase Plugin

**Name:** Supabase  
**Use case:** Full-stack Supabase project management, PostgreSQL database design, migrations, RLS policies, Auth, and Edge Functions.  
**Core functionality:**
- Supabase MCP integration for executing SQL, querying logs, managing branches, and deploying edge functions.
- Postgres and database design best practices (schema design, indexing, triggers, RLS audit).
- Client integrations for Next.js, React, SvelteKit, and Astro.
**Original source:** [supabase-community/supabase-plugin](https://github.com/supabase-community/supabase-plugin) (Official Site: [supabase.com](https://supabase.com))
