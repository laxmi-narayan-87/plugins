# Chrome DevTools Plugin

**Name:** Chrome DevTools  
**Use case:** Reliable web browser automation, in-depth debugging, performance analysis, and accessibility auditing in Google Chrome.  
**Core functionality:**
- Automated browser interaction and inspection via Puppeteer and Chrome DevTools MCP.
- Accessibility (a11y) audits and debugging based on web.dev guidelines.
- Largest Contentful Paint (LCP) and Core Web Vitals performance optimization.
- Cookie and session state debugging.
- JavaScript memory leak diagnostics.
**Original source:** [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
