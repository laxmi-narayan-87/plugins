# Cloudflare Plugin

**Name:** Cloudflare  
**Use case:** Build, deploy, and manage applications on Cloudflare Workers, storage, and AI using platform skills and Cloudflare MCP.  
**Core functionality:**
- Cloudflare Workers and Durable Objects development and best practices.
- Cloudflare Agents SDK workflows.
- Basin analytics, K2 durable logs, and R2 storage management.
- Framework deployment (Next.js with vinext, Astro, SvelteKit, React Router).
- Cloudflare One Zero Trust, Email routing/sending, and Turnstile bot protection.
**Original source:** [cloudflare/skills](https://github.com/cloudflare/skills) (Documentation: [developers.cloudflare.com](https://developers.cloudflare.com/))
