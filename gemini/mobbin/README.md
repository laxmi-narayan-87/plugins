# Mobbin Plugin

**Name:** Mobbin  
**Use case:** Search 600,000+ real application UI screens, analyze real-world design patterns, and redesign components within your design system.  
**Core functionality:**
- Search UI flows, screens, and sections from top production mobile and web applications.
- Screen redesign workflows backed by real-world design pattern evidence.
- Mobbin MCP server integration.
**Original source:** [mobbin/skills](https://github.com/mobbin/skills) (Documentation: [mobbin.com/mcp](https://mobbin.com/mcp))
