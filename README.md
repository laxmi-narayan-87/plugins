# Plugin Archive

A versioned archive of the plugin packages owned by this account. Each folder under `plugins/` mirrors the source-relative files exposed by the Plugin Creator registry. These are plugin manifests, skill instructions, docs, and any text assets readable from the registry; upstream runtime engines are not implied to be bundled.

## Plugins archived

- [reticle-verification](plugins/reticle-verification/)
- [beyondseo](plugins/beyondseo/)
- [artemis-android-qa](plugins/artemis-android-qa/)
- [serena-coding-agent](plugins/serena-coding-agent/)

## Handling notes

- Do not commit credentials, tokens, private user data, or environment files.
- Upstream repositories remain the source of truth for upstream engines and dependencies.
- This archive captures the registry files retrievable at commit time; binary assets or unavailable files may need a separate export.
